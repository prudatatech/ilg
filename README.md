# ILG Naturals - Kesari Nandan (केसरी नंदन)

Authentic Indian Stone-Ground Spices & Pure Kachi Ghani Mustard Oils web application built with **React 18**, **TypeScript**, and **Vite**.

## Features
- **Design & Branding**: Inspired by classic Indian spice heritage (signature spice red `#CA2100` and turmeric gold `#eeee22`)
- **Product Catalog**: Multi-variant weights (100g, 200g, 500g, 1kg, 1L, 5L) across Grounded Spices, Cold-Pressed Mustard Oils, Whole Spices, Blended Spices, Kesari Specials, and New Arrivals
- **Culinary Recipe Collection**: Interactive recipe book with ingredients, cooking methods, and dish photography
- **Shopping Cart**: Persistent basket with slide-in drawer and checkout flow
- **Fully Responsive**: Mobile, tablet, and desktop optimized

## Getting Started

### Install Dependencies
```bash
npm install
```

### Run Locally
```bash
npm run dev
```

### Production Build
```bash
npm run build
```

## Vercel Deployment
This repository is configured for zero-config Vite deployment on Vercel.
- Framework Preset: **Vite**
- Build Command: `npm run build`
- Output Directory: `dist`
